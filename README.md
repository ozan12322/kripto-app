# 🔐 Web Simulasi Kriptografi Klasik

Aplikasi web edukatif interaktif berbasis **Flask (Python)** untuk mensimulasikan proses enkripsi dan dekripsi algoritma Kriptografi Klasik secara rinci, transparan, dan langkah-demi-langkah.

## 🚀 Fitur Utama

1. **5 Algoritma Klasik**: Caesar, Vigenère, Affine, Hill (2x2 & 3x3), dan Playfair Cipher.
2. **Transparansi Perhitungan**: Dilengkapi langkah matematis eksplisit berbasis rumus LaTeX.
3. **UI Modern & Responsif**: Menggunakan Bootstrap 5 yang dilengkapi dengan fitur Dark Mode.
4. **Riwayat Aktivitas**: Menyimpan riwayat enkripsi/dekripsi dalam sesi pengguna.

## 💻 Cara Menjalankan Secara Lokal

1. Clone repositori: `git clone https://github.com/username/kripto-app.git`
2. Install dependensi: `pip install flask numpy`
3. Jalankan aplikasi: `python app.py`
4. Buka browser pada alamat: `http://127.0.0.1:5000`
